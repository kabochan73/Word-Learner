# カスタマイズガイド

Word Learnerは「誰でもgit cloneして、お題とルールを書き換えれば自分用のタイピングゲームを作れる」ことを意図的な設計目標にしている([01-overview.md](./01-overview.md))。管理画面(CMS)は作らない方針だが、その代わりに**コードを読めば迷わず改造できる**ことを重視する。

## カスタマイズの主目的: お題(ワード)の入れ替え

配布時点では、お題に日本語の意味・入力内容に英単語のスペルを入れた**一例**(英検5級/4級/3級の英単語学習)として公開している([01-overview.md](./01-overview.md))。このテンプレートで一番やりたいことは**配色やデザインの変更ではなく、お題のセットを自分の学びたい内容に入れ替えること**(例: TOEICの語彙に変える、別の意味↔スペルのペアに入れ替える等)。見た目のカスタマイズは目的ではないので、このガイドや`// CUSTOMIZE:`コメントも単語データ(`resources/js/lib/customize/words/`)周りを最優先で手厚くする。

編集対象になりうるファイルは`resources/js/lib/customize/`配下にまとめてある。それ以外の`lib/`配下(`judge.ts` `queue.ts` `format.ts`)はゲームの入力判定・出題順アルゴリズムなど触る必要のないロジックなので、カスタマイズ時に読む必要はない。

## 想定する編集者: 人間本人ではなくAIエージェント

実際にcloneした人が手でコードを書き換えることは想定しにくい。「このゲームのお題を英単語に入れ替えて」「お題をTOEICの語彙に変えて」のように、**その人が使っているAIコーディングエージェントに指示して単語セットを入れ替えさせる**のが現実的な使い方になる。そのため、このガイドと`// CUSTOMIZE:`コメントは人間向けの説明だけでなく、**AIエージェントがこのリポジトリを開いたときに迷わず単語データを編集できるようにする**ことを目的にしている。

- リポジトリのルートに`AGENTS.md`(または`CLAUDE.md`)を置き、「カスタマイズの要望が来たら`docs/customization.md`を読み、`// CUSTOMIZE:`コメントをgrepして該当箇所を編集する」という手順を明記する
- `// CUSTOMIZE:`コメントは一言で「何が変わるか」が分かるように書く(AIエージェントがコメント文だけで目的のファイルを特定できるように)
- このガイド自体も、人間が読む前提の長い説明ではなく、エージェントがそのまま参照して行動できる「ファイル⇔変更内容」の対応表を主にする(下記の表)

## コメント規約: `// CUSTOMIZE:`

カスタマイズを前提にしたファイル・箇所には、必ず`// CUSTOMIZE:`で始まるコメントを付ける。「ここを変えると何が変わるか」を一言で書く。

```ts
// CUSTOMIZE: ここに単語を追加すると5級のお題に出るようになる。wordは正規スペル1パターンのみ対応
export const GRADE1_WORDS: Word[] = [
  { meaning: "猫", word: "cat" },
];
```

```ts
// CUSTOMIZE: 制限時間(秒)。複数モードにしたい場合はここを配列化する
export const DURATION_SEC = 60;

// CUSTOMIZE: 何問ノーミス連続正解でボーナスが入るか
export const BONUS_COMBO_THRESHOLD = 5;

// CUSTOMIZE: ボーナスで増える秒数
export const BONUS_SECONDS = 2;
```

このコメントは`grep -rn "CUSTOMIZE" resources/js/`で一覧できる。カスタマイズ可能な箇所を網羅的に把握できるようにするのが目的なので、実装時にこのマーカーを漏らさず付けることを徹底する(コードレビュー観点の1つとする)。

## 編集すればいいファイル一覧

| やりたいこと | 編集するファイル |
|---|---|
| **お題の単語セットを入れ替える(最優先・メインの使い方)** | `resources/js/lib/customize/words/grade{1,2,3}.ts`([frontend/game-engine.md](./frontend/game-engine.md)) |
| 級の区分そのものを変える(英検以外の区分にする、級の数を変える等) | `resources/js/lib/customize/words/index.ts`の`Grade`型・`WORDS_BY_GRADE`(クライアント側だけで完結。バックエンドは級の一覧を持たないため変更不要) |
| 制限時間・コンボボーナスの条件を変える | `resources/js/lib/customize/game-config.ts` |

見た目(アプリ名表示・配色・デザイン)の変更は目的外。バックエンド(認証・DB・ランキング計算)は単語セット・級の一覧に依存しないため、級を増減してもバックエンドは触らずに済む。
