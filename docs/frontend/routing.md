# サイトマップ

| パス | 認証 | 内容 |
|---|---|---|
| `/` | 不要 | トップページ。2カラムレイアウト: メイン側に**級選択・モード選択・「START GAME」ボタン**、サイドバーに選択中の級のランキング(上位10件) |
| `/login` | 未ログインのみ | ログインフォーム |
| `/register` | 未ログインのみ | 登録フォーム(名前+パスワード) |
| `/play?grade=&mode=` | 不要 | ゲーム画面。トップページで選択済みの級・モードを引き継いで即スタート→タイピング→結果→(チャレンジモード かつ ログイン済みなら)スコア保存。`grade`/`mode`が欠落・不正なら`/`へリダイレクト(バックエンド・フロントエンド2段階で検証、[api.md](../api.md)) |

ログインはどのページに入れるかではなく、**スコアをランキングに保存できるかどうか**だけに関わる。`/play`はログインしていなくても遊べ、未ログインのままプレイすると結果画面でスコアは保存されず「ログインするとランキングに記録されます」という導線を表示する([frontend/game-engine.md](./game-engine.md))。

マイページ(プレイ履歴)機能は持たない。クイズではなくタイピングゲームであり、トップページのランキングがあれば十分という判断。

ランキングは専用ページを持たず、トップページ(`/`)のサイドバーとして表示する。認証不要で誰でも見られる。モバイル幅ではサイドバーをメインコンテンツの下に積む(1カラム)。

級(このリポジトリでは英検5級/4級/3級)は難易度が異なるためランキングも別物になる。トップページには「SELECT LEVEL」の級選択(ドロップダウン)と「SELECT MODE」のモード選択(学習/チャレンジ)を置き、この**級選択の状態をゲーム開始とランキング表示の両方で共有する**(ランキング専用のタブは持たない)。級の選択を変えると`router.reload({ only: ['grade', 'ranking'], data: { grade } })`でトップページ自身にpartial reloadし、`ranking`propだけをLaravel側(`HomeController`)で再計算して受け取る(ページ全体の再読み込みはしない、専用のJSON APIも持たない。[backend/folder-structure.md](../backend/folder-structure.md))。デフォルトは5級。「START GAME」を押すと選択中の`grade`・`mode`をクエリパラメータとして`/play`に遷移し、`/play`では選択UIを出さずにそのままゲームを開始する。

## アクセス制御

ログイン必須のページは無い。ログイン状態は`usePage().props.auth.user`としてすべてのページに共有されており、別途確認のfetchをする必要はない(`HandleInertiaRequests::share()`、[backend/auth.md](../backend/auth.md))。トップページの導線表示、`/play`の結果画面でスコアを保存するかどうかの分岐などに、このpropをそのまま使う。

## 画面遷移

```
/(級・モード選択) ──(ログインリンク)──→ /login ──(登録リンク)──→ /register
│                                                  │
│                                                  └─(ログイン成功)──→ /
└─(START GAME)───────────────────────────────────────────→ /play?grade=&mode=

/play ──(タイムアップ)──→ 結果表示(同一ページ内)
  ├─ 学習モード                        → 保存せず「チャレンジモードで挑戦しよう」導線
  ├─ チャレンジモード・ログイン済み      → スコアをPOSTして保存 → 「ランキングを見る」導線
  └─ チャレンジモード・未ログイン        → 保存せず「ログインするとランキングに記録されます」導線(/login へ)
```
