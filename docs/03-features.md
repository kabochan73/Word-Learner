# 機能一覧

[01-overview.md](./01-overview.md)の要件を元に、必要な機能を洗い出したもの。「必須」はMVPに入れる前提、「あったら良い」は今回は見送り、将来やりたくなったら検討する。

## 1. 認証(Laravel + Inertia)

**必須**

- ユーザー登録(名前+パスワード、名前の重複チェック)
- ログイン(Laravelセッション開始)
- ログアウト(セッション破棄)
- ログイン状態の共有(`HandleInertiaRequests::share()`で`auth.user`を全ページpropsに乗せる。クライアント側で別途チェックAPIを呼ぶ必要はない)

**あったら良い(見送り)**

- パスワードリセット機能(メール不要の方針のため見送り)
- 名前の変更機能(なし)
- パスワード変更機能(なし)
- 退会機能

## 2. ゲームプレイ(Inertia + React)

**必須**

- トップページでの開始前の級選択(このリポジトリでは英検5級/4級/3級)とモード選択(学習モード/チャレンジモード)。選択後「START GAME」で選択済みの状態のまま`/play`に遷移([frontend/game-engine.md](./frontend/game-engine.md)、[frontend/routing.md](./frontend/routing.md))
- お題(このリポジトリでは「日本語の意味」)の表示。選んだ級のお題セットをシャッフルして使い切るまで繰り返さない「バッグ方式」で出題し、偏りを防ぐ([frontend/game-engine.md](./frontend/game-engine.md))
- 入力欄は、入力済みの文字と残りの文字(このリポジトリでは英単語のスペル)を重ねて表示する。学習モードでは残りの文字をグレーで見せることでヒントを兼ねる。チャレンジモードでは入力済みの文字しか表示しない(答えは見えない)
- 入力判定(1文字ずつ、ミスは無視して再入力を促す)
- 60秒カウントダウンタイマー。表示は`mm:ss`形式(タイムボーナスで60秒を超えうるため)
- **チャレンジモードのみ**: 1問あたり7秒の制限時間を設け、超えたら自動的にミス扱いでスキップして次の単語へ([frontend/game-engine.md](./frontend/game-engine.md))。視覚的なカウントダウン表示は無し
- コンボ管理(ノーミスで単語を打ち切るとコンボ+1、ミスまたは時間切れスキップがあれば0にリセット)
- タイムボーナス(コンボ5ごとに残り時間+2秒)
- スコア計算(正解して完了した単語数。時間切れスキップは加算しない)
- スタート/終了の制御(タイムアップで自動終了)
- 終了後の結果画面(スコア表示)
- **チャレンジモードかつログイン済みの場合のみ**結果を`POST /game-sessions`に送信して保存。学習モードでは保存自体を行わない。チャレンジモードで未ログインなら保存せず「ログインするとランキングに記録されます」という導線を表示([frontend/game-engine.md](./frontend/game-engine.md))

**あったら良い(見送り)**

- ボーナス発生時の視覚・音のフィードバック
- ミス時の視覚フィードバック(入力欄が揺れる等)
- プレイ中の残りコンボ数表示

## 3. ランキング(Laravel + Inertia)

**必須**

- 級ごとのランキング取得・表示(`game_sessions`を`grade`で絞って`user_id`でGROUP BYして最高スコアを集計、上位10件固定をスコア降順)。チャレンジモードのスコアのみ対象
- 専用ページは持たず、トップページ(`/`)のサイドバーに表示する。表示する級はトップページの「SELECT LEVEL」選択と連動して切り替わる(ランキング専用のタブは持たない。専用のJSON APIも持たず、トップページのInertiaページがpropとして渡す、[frontend/routing.md](./frontend/routing.md))

**あったら良い(見送り)**

- 自分の現在の順位をランキング外でも表示
- 期間別ランキング(本日/今週/全期間など)

## 4. 共通基盤

**必須**

- Inertiaのフォームヘルパー(`useForm`)でのPOST送信・バリデーションエラー表示([frontend/folder-structure.md](./frontend/folder-structure.md))
- フォームの入力バリデーション(必須項目、パスワード最小文字数など)
- ローディング状態の表示(フォーム送信中)
- レスポンシブ対応(最低限、PC/スマホで崩れない程度)

**あったら良い(見送り)**

- トースト等の通知UI
- ダークモード対応
